# Личный проект «Keks» для самостоятельной работы

* Студент: [Артем Ткачев](https://up.htmlacademy.ru/react-individual/3/user/2416991).

## О проекте

«Keks» — веб-приложение кондитерской, разработанное в рамках самостоятельной работы на курсе HTML Academy.

## Технологии

* React
* TypeScript
* Redux Toolkit
* React Router
* Axios
* Vite
* Vitest
* React Testing Library
* Leaflet

## Установка

Установить зависимости:

```bash
npm install
```

Запустить проект в режиме разработки:

```bash
npm run dev
```

После запуска приложение будет доступно по адресу, который выведет Vite в терминале. Либо в терминале "o" + enter.

## Скрипты

### `npm run dev`

Запускает приложение в режиме разработки с помощью Vite.

### `npm run build`

Проверяет TypeScript и собирает production-версию приложения.

Результат сборки помещается в директорию `dist`.

### `npm run preview`

Запускает локальный сервер для просмотра production-сборки.

Перед запуском необходимо выполнить:

```bash
npm run build
```

### `npm run lint`

Запускает ESLint и проверяет исходный код проекта на соответствие правилам линтинга.

### `npm test`

Запускает тесты с помощью Vitest.

### `npm run test:coverage`

Запускает тесты и формирует отчёт о покрытии кода.
